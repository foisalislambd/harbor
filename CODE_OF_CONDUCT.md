# Code of Conduct

Harbor is worked on in public. Be direct, assume good intent, and keep the discussion on the software.

## Expected

- Comment on the change, not the person.
- Accept correction on design and code.
- Give reviewers enough context to reproduce a bug.

## Not accepted

- Harassment, insults, or posting someone else's private data.
- Opening issues or pull requests for unrelated promotions.

Maintainers may edit or close comments and contributions that break these rules. Report conduct problems the same way as a security issue: a private advisory on this repository, not a public issue.
